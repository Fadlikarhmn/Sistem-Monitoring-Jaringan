# Sistem-Monitoring-Jaringan
# Sebuah kantor kecil ingin memantau perangkat yang terhubung ke jaringan mereka. Sistem sederhana ini akan menampilkan daftar perangkat, memungkinkan pencarian perangkat berdasarkan nama atau IP, dan mendeteksi perangkat yang tidak aktif.
# 1. Array 2D: Data perangkat jaringan disimpan dalam array 2D dengan kolom untuk nama, IP, dan status.
2. Fungsi: Program dibagi menjadi metode sederhana untuk setiap fitur.
3. Perulangan dan Percabangan: Menggunakan while dan if-else untuk navigasi menu.
4. Searching: Mencari perangkat dengan mencocokkan substring dalam nama atau IP perangkat.
